## 4. Tokens PR (small, exact)

**File:** `src/app/globals.css`.

1. Tokens. Add a plain `:root` block directly after the light-mode accent block (after line 74) so the variables are
   always emitted. Do not put them in `@theme` (v4 drops unused `@theme` vars; `--motion-*` is not a theme namespace anyway).
   Never define `--ease-out` or any `--ease-*` in `@theme` (it overrides Tailwind's built-in curve).

   ```css
   :root {
     --motion-dur-fast: 120ms;
     --motion-dur-base: 180ms;
     --motion-dur-slow: 240ms;
     --motion-ease-out: cubic-bezier(0.16, 1, 0.3, 1);
   }
   ```

   Consumers use `duration-[var(--motion-dur-fast)]` / `ease-[var(--motion-ease-out)]` (or the keyframe shorthands
   shipped later). Prettier will lowercase/normalize `.16` to `0.16`; same value.

2. Global reduced-motion net. Insert it **above** the existing "Reduced motion: quiet the remaining page-chrome
   animations" block (`globals.css:1067`), so that block stays last in the file as its own comment requires, and after
   the CopilotKit rules (the net is `!important`; it must win the tie against `.copilotKitInput`'s `!important` transition).
   The brief's net verbatim would break the games: DESIGN.md:695-701 and the RC-6 comment at `globals.css:1067-1069`
   require games to keep their CSS animations (`hextris-*`, `ts-*`, `pg2`) under reduced motion, and `animation-duration:
.01ms; iteration-count: 1` would snap them to their end state. So the net carries a game exemption:

   ```css
   @media (prefers-reduced-motion: reduce) {
     *:not(.animate-spin, [data-motion-exempt], [data-motion-exempt] *),
     *:not([data-motion-exempt] *)::before,
     *:not([data-motion-exempt] *)::after {
       animation-duration: 0.01ms !important;
       animation-iteration-count: 1 !important;
       transition-duration: 0.01ms !important;
     }
   }
   ```

   The same PR adds `data-motion-exempt` (on a `className="contents"` wrapper `<div>`) at the three game mount points:
   `components/game/game-loader.tsx` (around `MotionConfig`), `components/sections/game.tsx` (around the existing
   `MotionConfig reducedMotion="never"`), and the Password Game 2 route `app/games/password-game/page.tsx`. No game
   code is portaled out of those subtrees (no `createPortal` in `components/game/`). Run the games' unit and
   e2e suites; they must not change.

   Effect on chrome (checked): marquee, shimmer, aurora, glow, assistant-message already use `animation: none` in
   the existing blocks and keep doing so; the net adds the transition side (Tailwind `transition-*`, CopilotKit's
   `transition` rules) and any future `animation`. It does NOT remove end-state transforms, which is why every
   transform in new code still needs `motion-safe:`.

3. `MotionConfig`: **not needed, already shipped** (`providers.tsx:12`, `reducedMotion="user"`, games opt out). Add nothing.
   No `LazyMotion`/`m.*` work either: all five spots are CSS-only, and the brief forbids rewriting existing `motion.*`.

## 5. Visual-capture config (before the first motion PR)

Current state: `playwright.config.ts` sets neither `reducedMotion` nor `animations`; there are no `toHaveScreenshot`
specs in `e2e/` and no Snapvisor config in the repo (the visual baseline lives outside it). CI has a Lighthouse job
(`ci.yml`), usable for the CLS/TBT evidence. Needed:

- `playwright.config.ts`: `use.reducedMotion: "reduce"` and `expect: { toHaveScreenshot: { animations: "disabled" } }`.
  Caveat: `reducedMotion: "reduce"` flips the chrome onto its reduced paths in every existing spec (for example
  `hero-photo.tsx` pokes). Games ignore it. If that is too wide, scope it to a dedicated `visual` project instead
  of the global `use`.
- `e2e/helpers.ts`: add a `freezeMotion(page)` helper that injects `*,*::before,*::after{animation:none!important;
transition:none!important}` (`page.addStyleTag`/`addInitScript`) for screenshot specs. Needed on top of the two
  settings above because framer opacity fades survive reduced mode and the games ignore the media query.
- Snapvisor capture script (wherever it lives): same two flags plus the injected style.
